So Sánh & Rút Ra Kết Luận (Câu c)

Đối chiếu chập hình hai cách nhóm vectơ $(\vec{a}+\vec{b})+\vec{c}$ và $\vec{a}+(\vec{b}+\vec{c})$

Nhánh a: $(\vec{a} + \vec{b}) + \vec{c}$
• Nhóm trước: $\vec{OA} + \vec{AB} = \mathbf{\vec{OB}} = (1+4, 3+1) = \mathbf{(5, 4)}$
• Cộng tiếp $\vec{c}$: $\mathbf{\vec{OB}} + \vec{BC} = \mathbf{\vec{OC}} = (5+3, 4-1) = \mathbf{(8, 3)}$
• Vectơ tổng cuối cùng là $\mathbf{\vec{OC}}$.
Nhánh b: $\vec{a} + (\vec{b} + \vec{c})$
• Nhóm trước: $\vec{AB} + \vec{BC} = \mathbf{\vec{AC}} = (4+3, 1-1) = \mathbf{(7, 0)}$
• Cộng với $\vec{a}$: $\vec{OA} + \mathbf{\vec{AC}} = \mathbf{\vec{OC}} = (1+7, 3+0) = \mathbf{(8, 3)}$
• Vectơ tổng cuối cùng cũng chính là $\mathbf{\vec{OC}}$.
KẾT LUẬN SƯ PHẠM (Câu c):
Phép cộng vectơ có tính chất kết hợp. Với ba vectơ $\vec{a}, \vec{b}, \vec{c}$ tùy ý, ta luôn có:
$(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c}) = \vec{a} + \vec{b} + \vec{c}$
